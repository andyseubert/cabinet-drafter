# Privacy

CabinetDrafter is an offline-first static application.

- Cabinet/project data is processed in the browser.
- Browser autosave uses local browser storage.
- Project JSON files are written only when the user chooses or authorizes a local file.
- The core application has no analytics, account system, advertising, or project-data upload service.
- Hosting the static files on GitHub Pages does not change the application's project-data flow.

Users should review their browser and GitHub privacy settings separately.
