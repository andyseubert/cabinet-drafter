CabinetDrafter 1.2.2

Free cabinet design, material planning, nesting, and 3D.

Start here: open index.html. Nothing needs to be installed. SketchUp is optional.

Quick start

  1. Open index.html in a modern browser.
  2. Choose inches or millimeters.
  3. Add or edit cabinets.
  4. Choose Frameless, Face frame · overlay, or Face frame · inset for each cabinet.
  5. Enter drawer/opening heights and inspect the 3D preview.
  6. Review warnings, the BOM, cut list, and sheet layouts before buying/cutting material.
  7. As you build, check off completed cut parts and enter full sheets already on hand.
  8. Use Save Project JSON to keep a portable project file.

Drawer and open-space syntax

D means Drawer. O means Open — the letter O ("oh"), not zero.

D7, D7, D9
D9, O15
D9, Open 15, D7

Open-shelf cabinets accept clear opening heights such as 9.5, 12, auto.

Face frames

CabinetDrafter supports frameless, face-frame overlay, and face-frame inset fronts. Configure stile width, rail width, thickness/material, overlay, and inset reveal in the Face-frame options section.

Current limit: face frames are perimeter-only: two full-height stiles plus top and bottom rails. Intermediate rails between individual drawers/cubbies are not generated yet.

Materials

Plywood parts are nested on configured sheets with kerf, trim, and optional cherry grain locking. Face-frame members are treated separately as solid linear stock. Sheet nesting finds a valid layout but does not guarantee the mathematical minimum number of sheets.

Build progress and inventory

Progress is tracked by individual physical plywood cut part, with assembly checkboxes for whole carcasses, toe-kick bases, drawers, doors/fronts, and shelf sets. Completed work stays in the cabinet design and 3D model, but is removed from remaining-work nesting. Enter full, uncut usable sheets on hand by material to get a shopping list of additional sheets still to buy. Scraps and partial sheets are not counted as full-sheet inventory.

Remaining layout sheets can be selected individually before printing.

3D preview

The 3D preview runs entirely in the browser. Orbit, pan, zoom, hide/show parts, switch preset views, and save PNG images. SketchUp export is optional.

SketchUp export

SketchUp is optional. After downloading the Ruby script, in SketchUp Pro open Extensions → Developer → Ruby Console, paste the exact load ... command shown by CabinetDrafter, and press Enter. By default, the script replaces the prior Generated Cabinet Lineup group. Turn off Replace prior Generated Cabinet Lineup in SketchUp before downloading to keep existing generated cabinets and add the new export as a separate timestamped group.

Privacy

Project geometry is processed locally. CabinetDrafter has no account system, analytics, ads, or project-data upload service.

Before cutting

Measure and verify before cutting. Confirm actual material thickness, hardware clearances, installation conditions, and every warning shown by CabinetDrafter.
